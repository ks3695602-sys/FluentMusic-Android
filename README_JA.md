## 🌟 FluentMusic について

**FluentMusic for Android** は、**Jayprakash Sahu** によって保守されているオープンソースの音楽クライアントです。[rukamori](https://github.com/rukamori) 氏による [ArchiveTune](https://github.com/rukamori/ArchiveTune) をベースに **GNU General Public License v3.0 (GPL-3.0)** に基づき合法的にフォークされています。

高度な **Android Liquid Glass** シェーダーエンジン（[Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)）を採用し、フロストリキッドガラスカプセル、動的ブラーヘッダー、同期されたグローバルガラス設定などの最新UIを提供します。

---

## ✨ 主な機能

- 💧 **Liquid Glass UI アーキテクチャ**: `io.github.kyant0:backdrop` を採用し、ボトムナビゲーション、アクションボタン、検索バー、設定トグルに美しい屈折・反射エフェクトを提供。
- 🌫️ **プログレッシブブラーヘッダー**: コンテンツのスクロールに合わせてヘッダーが美しくぼかし変化。
- 🎛️ **同期された Liquid Glass 設定**: ブラー半径、屈折強度、ガラス透明度をリアルタイムで一括調整可能。
- 🎵 **同期歌詞 & ビジュアル**: 単語単位のアニメーションと翻訳に対応したライブ歌詞表示。
- 🔒 **プライバシー重視**: トラッキングなし、ローカルキャッシュおよびオフライン再生。
